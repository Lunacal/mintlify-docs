---
title: "Cancel booking"
description: "Cancel a booking, or all remaining bookings in a recurring series."
api: "POST https://app.lunacal.ai/api/mcp/bookings/cancel"
authMethod: "bearer"
---

Cancels a booking. Lunacal sends cancellation emails, removes the event from connected calendars, and sets the booking status to `CANCELLED`.

## Body

<ParamField body="uid" type="string" required>
  UID of the booking to cancel.
</ParamField>

<ParamField body="cancellationReason" type="string">
  Reason shown to attendees in the cancellation email.
</ParamField>

<ParamField body="allRemainingBookings" default="false" type="boolean">
  For recurring bookings, set to `true` to cancel all future occurrences in the series.
</ParamField>

## Response

Returns the updated booking with `status` set to `CANCELLED`.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/mcp/bookings/cancel \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "uid": "8f2b1c3e-4d5a-4b6c-9e7f-0a1b2c3d4e5f",
    "cancellationReason": "Schedule conflict"
  }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "uid": "8f2b1c3e-4d5a-4b6c-9e7f-0a1b2c3d4e5f",
  "status": "CANCELLED",
  "cancellationReason": "Schedule conflict"
}
```

</ResponseExample>
