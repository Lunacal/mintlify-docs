---
title: "List event types"
description: "Retrieve the event types for your account."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Returns the user's event types, both personal and team. Use an event type `id` from this list with [Get availability](/api/endpoints/get-availability) and [Create booking](/api/endpoints/bookings-create).

## Body

<ParamField body="filters" type="object">
  Optional filters.

  <Expandable title="properties">
    <ParamField body="teamIds" type="integer[]">
      Only return event types for these teams.
    </ParamField>
  </Expandable>
</ParamField>

The response is the same one the LunaCal platform returns for this route.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/event-types/list \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "filters": {
    "teamIds": [
      12
    ]
  }
}'
```

</RequestExample>
