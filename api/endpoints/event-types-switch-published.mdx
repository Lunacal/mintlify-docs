---
title: "Switch published"
description: "Publish or unpublish an event type."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Sets whether an event type is published (bookable) or hidden from the public booking page.

## Body

<ParamField body="eventId" type="integer" required>
  ID of the event type.
</ParamField>

<ParamField body="isPublished" type="boolean" required>
  Pass `true` to publish, `false` to hide.
</ParamField>

<ParamField body="teamId" type="integer">
  Team ID, for team event types.
</ParamField>

The response is the same one the LunaCal platform returns for this route.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/event-types/switch-published \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "eventId": 42,
  "isPublished": true
}'
```

</RequestExample>
