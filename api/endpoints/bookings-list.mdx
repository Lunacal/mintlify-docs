title: "List bookings"
description: "Retrieve bookings for the account that owns the API key."

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Returns the bookings for the user that owns the API key, using the same logic as the LunaCal web app.

## Request

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/bookings/list \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

</RequestExample>

<Warning>
  The route and purpose are confirmed, but the request-body parameters (such as filters or pagination) and the response schema have not yet been documented. Replace `{}` with the body your integration needs.
</Warning>
