---
title: "List bookings"
description: "Retrieve bookings for the account that owns the API key."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Lists bookings for the key's user. `filters.status` is required. Use a booking `uid` from `bookings` when you reschedule or cancel. Pagination is an offset: pass `nextCursor` back as `cursor`. `nextCursor` is `null` on the last page.

## Body

<ParamField body="filters" type="object" required>
  Filters for the list.

  <Expandable title="properties">
    <ParamField body="status" type="string" required>
      One of `upcoming`, `recurring`, `past`, `cancelled`, `unconfirmed`.
    </ParamField>

    <ParamField body="teamIds" type="integer[]">
      Only bookings for these teams.
    </ParamField>

    <ParamField body="eventTypeIds" type="integer[]">
      Only bookings for these event types.
    </ParamField>

    <ParamField body="search" type="string">
      Free-text search.
    </ParamField>

    <ParamField body="startDate" type="string">
      Earliest booking start. ISO 8601 date-time including a timezone offset.
    </ParamField>

    <ParamField body="endDate" type="string">
      Latest booking start. ISO 8601 date-time including a timezone offset.
    </ParamField>

    <ParamField body="userIds" type="integer[]">
      Only bookings for these user ids.
    </ParamField>

    <ParamField body="attendeeEmail" type="string">
      Only bookings whose attendee email matches. Must be a valid email address.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="limit" type="integer" default="10">
  Page size. Minimum 1, maximum 100. Omitted means 10.
</ParamField>

<ParamField body="cursor" type="integer">
  Offset taken from a previous response's `nextCursor`.
</ParamField>

## Response

```json
{
  "bookings": [],
  "recurringInfo": [],
  "nextCursor": null
}
```

`bookings` contains the rows for that status. Read `uid` from each row when you cancel or reschedule. `nextCursor` is the next `cursor`, or `null` when the page is the last one. The other fields on each booking are the ones the Lunacal bookings list uses internally. Do not treat undocumented fields as a contract.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/bookings/list \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "filters": {
    "status": "upcoming"
  },
  "limit": 20
}'
```

</RequestExample>
