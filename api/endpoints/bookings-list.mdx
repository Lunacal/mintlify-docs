---
title: "List bookings"
description: "Retrieve bookings for the account that owns the API key."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Lists the user's bookings. Use a booking `uid` from this list to reschedule or cancel. Results are paginated: pass the `nextCursor` from a previous response as `cursor` to get the next page.

## Body

<ParamField body="filters" type="object" required>
  Filters for the list.

  <Expandable title="properties">
    <ParamField body="status" type="string" required>
      One of `upcoming`, `recurring`, `past`, `cancelled`, `unconfirmed`.
    </ParamField>

    <ParamField body="teamIds" type="integer[]">
      Only bookings for these teams.
    </ParamField>

    <ParamField body="eventTypeIds" type="integer[]">
      Only bookings for these event types.
    </ParamField>

    <ParamField body="search" type="string">
      Free-text search.
    </ParamField>

    <ParamField body="startDate" type="string">
      Earliest booking start. ISO 8601 date-time including a timezone offset.
    </ParamField>

    <ParamField body="endDate" type="string">
      Latest booking start. ISO 8601 date-time including a timezone offset.
    </ParamField>

    <ParamField body="attendeeEmail" type="string">
      Only bookings with this attendee.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="limit" default="20" type="integer">
  Page size, from 1 to 100.
</ParamField>

<ParamField body="cursor" type="integer">
  Offset taken from a previous response's `nextCursor`.
</ParamField>

The response is the same one the LunaCal platform returns for this route.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/bookings/list \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "filters": {
    "status": "upcoming"
  },
  "limit": 20
}'
```

</RequestExample>
