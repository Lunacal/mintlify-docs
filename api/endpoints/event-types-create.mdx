---
title: "Create event type"
description: "Create a new event type."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Creates an event type owned by the user. Use [Switch published](/api/endpoints/event-types-switch-published) afterwards to publish or hide it.

## Body

<ParamField body="title" type="string" required>
  Event type title.
</ParamField>

<ParamField body="slug" type="string" required>
  URL slug.
</ParamField>

<ParamField body="length" type="integer" required>
  Duration in minutes.
</ParamField>

<ParamField body="description" type="string">
  Description.
</ParamField>

<ParamField body="hidden" type="boolean">
  Hide the event type from the public booking page.
</ParamField>

<ParamField body="teamId" type="integer">
  Create the event type under this team.
</ParamField>

<ParamField body="schedulingType" type="string">
  One of `ROUND_ROBIN`, `COLLECTIVE`, `MANAGED`.
</ParamField>

<ParamField body="locations" type="object[]">
  Meeting locations.
</ParamField>

<ParamField body="bookingFields" type="object[]">
  Custom booking questions.
</ParamField>

<ParamField body="metadata" type="object">
  Additional metadata.
</ParamField>

The response is the same one the LunaCal platform returns for this route.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/event-types/create \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "title": "30 min intro call",
  "slug": "intro-call",
  "length": 30
}'
```

</RequestExample>
