---
title: "Create event type"
description: "Create a new event type."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Creates an event type owned by the key's user. `title`, `slug`, and `length` are required. `bookingFields` is not part of this body. Add questions later with [Update event type](/api/endpoints/event-types-update). Unknown keys are dropped, so a `bookingFields` property here does nothing.

`isPublished` defaults to the database default (`true`) when omitted. `hidden` defaults to false when omitted. To keep a new event type off the public page, send `isPublished: false` or follow up with [Switch published](/api/endpoints/event-types-switch-published).

## Body

<ParamField body="title" type="string" required>
  Event type title.
</ParamField>

<ParamField body="slug" type="string" required>
  URL slug.
</ParamField>

<ParamField body="length" type="integer" required>
  Duration in minutes.
</ParamField>

<ParamField body="description" type="string">
  Description.
</ParamField>

<ParamField body="hidden" type="boolean">
  Hide the event type from the public booking page.
</ParamField>

<ParamField body="teamId" type="integer">
  Create the event type under this team.
</ParamField>

<ParamField body="schedulingType" type="string">
  Required when `teamId` is set. One of `ROUND_ROBIN`, `COLLECTIVE`, `MANAGED`.
</ParamField>

<ParamField body="locations" type="object[]">
  Meeting locations. Optional on create.
</ParamField>

<ParamField body="isPublished" type="boolean">
  Whether the event type is on the public booking page.
</ParamField>

<ParamField body="metadata" type="object">
  Event type metadata. Optional.
</ParamField>

A successful call returns the new event type, including its `id`. Use that `id` for later updates.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/event-types/create \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "title": "30 min intro call",
  "slug": "intro-call",
  "length": 30
}'
```

</RequestExample>
