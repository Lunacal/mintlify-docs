---
title: "Delete event type"
description: "Delete an event type while keeping its booking history."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Deletes an event type. It is removed from listings and can no longer be booked. Existing booking history is preserved.

## Body

<ParamField body="id" type="integer" required>
  ID of the event type to delete.
</ParamField>

## Response

<ResponseField name="id" type="integer">
  ID of the deleted event type.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/event-types/delete \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "id": 42 }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "id": 42
}
```

</ResponseExample>
