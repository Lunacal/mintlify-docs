---
title: "Cancel booking"
description: "Cancel an existing booking."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Cancels a booking by `uid` (not the numeric id). This cannot be undone, so confirm with the user first.

## Body

<ParamField body="uid" type="string" required>
  UID of the booking. Get it from List bookings.
</ParamField>

<ParamField body="cancellationReason" type="string">
  Reason for cancelling. Pass one if LunaCal requires it.
</ParamField>

<ParamField body="allRemainingBookings" type="boolean">
  Also cancel the rest of a recurring series.
</ParamField>

The response is the same one the LunaCal platform returns for this route.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/bookings/cancel \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "uid": "abc123xyz",
  "cancellationReason": "Host unavailable"
}'
```

</RequestExample>
