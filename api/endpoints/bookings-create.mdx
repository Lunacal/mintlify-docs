title: "Create booking"
description: "Create a booking through the API."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Creates a booking for the account that owns the API key. Call [Booking questions](/api/endpoints/booking-questions) first to find out which questions must be answered.

## Request

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/bookings/create \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

</RequestExample>

<Warning>
  The route and purpose are confirmed, but the request-body parameters and the response schema have not yet been documented. Replace `{}` with the body your integration needs.
</Warning>
