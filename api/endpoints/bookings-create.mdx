---
title: "Create booking"
description: "Create or reschedule a booking."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Books a slot on an event type. Call [Get availability](/api/endpoints/get-availability) first and pass one of the returned start times. This route does not check that the slot is still free.

A bad API key returns `401`, with message `Invalid or missing credentials`.

To reschedule, send the same body with `rescheduleUid` set to the booking `uid` and a new `start`. The MCP tool `reschedule_booking` is a separate name for this operation. The HTTP field is `rescheduleUid` on this route.

## Body

<ParamField body="eventTypeId" type="integer" required>
  ID of the event type to book.
</ParamField>

<ParamField body="start" type="string" required>
  Start time. ISO 8601 date-time including a timezone offset.
</ParamField>

<ParamField body="end" type="string">
  End time. ISO 8601 date-time including a timezone offset.
</ParamField>

<ParamField body="timeZone" type="string" required>
  IANA timezone of the attendee.
</ParamField>

<ParamField body="responses" type="object" required>
  Attendee details and booking answers.

  <Expandable title="properties">
    <ParamField body="name" type="string" required>
      Attendee name.
    </ParamField>

    <ParamField body="email" type="string" required>
      Attendee email.
    </ParamField>

    <ParamField body="guests" type="string[]">
      Additional guest emails.
    </ParamField>

    <ParamField body="notes" type="string">
      Notes for the host.
    </ParamField>

    <ParamField body="location" type="string">
      Selected location value, for example `integrations:daily` or an address.
    </ParamField>

    <ParamField body="rescheduleReason" type="string">
      Reason, when rescheduling.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="rescheduleUid" type="string">
  UID of the booking to move. Get it from List bookings.
</ParamField>

<ParamField body="language" type="string" required>
  Language code, for example `en`. There is no default. Omitting it fails validation.
</ParamField>

<ParamField body="metadata" type="object" required>
  String values only. Send `{}` when you have nothing to store.
</ParamField>

<ParamField body="bookingUids" type="string[]" required>
  Send `[]` for a normal booking.
</ParamField>

<ParamField body="slots" type="object[]" required>
  Send `[]` for a single slot. Package and recurring bookings put each slot here as `{ "start", "end" }`.
</ParamField>

A successful call returns the booking that was created or moved. If the slot was taken, look up availability again and choose another start time.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/bookings/create \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "eventTypeId": 42,
  "start": "2026-11-03T10:00:00+05:30",
  "timeZone": "Asia/Kolkata",
  "language": "en",
  "metadata": {},
  "responses": {
    "name": "Jane Doe",
    "email": "jane@example.com"
  },
  "bookingUids": [],
  "slots": []
}'
```

</RequestExample>
