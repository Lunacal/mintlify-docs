---
title: "Get availability"
description: "Retrieve open booking slots for an event type."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Returns open slots for an event type between `startTime` and `endTime`. Call this before [Create booking](/api/endpoints/bookings-create). Pass `eventTypeId`, or pass both `eventTypeSlug` and `usernameList`. Sending neither fails validation.

## Body

<ParamField body="startTime" type="string" required>
  Start of the range. ISO 8601 date-time with an offset, for example `2026-11-02T00:00:00+05:30`.
</ParamField>

<ParamField body="endTime" type="string" required>
  End of the range. Same format as `startTime`.
</ParamField>

<ParamField body="eventTypeId" type="integer">
  Event type id. A numeric string is accepted. Required unless you send `eventTypeSlug` and `usernameList`.
</ParamField>

<ParamField body="eventTypeSlug" type="string">
  Event type slug. Must be sent together with `usernameList`.
</ParamField>

<ParamField body="usernameList" type="string[]">
  Host usernames. Must be sent together with `eventTypeSlug`.
</ParamField>

<ParamField body="timeZone" type="string">
  IANA timezone used when presenting slots, for example `Asia/Kolkata`. Optional. Send it. Slot times are stored in UTC, and this is how you ask for a local view.
</ParamField>

<ParamField body="duration" type="string">
  Length in minutes for event types that offer more than one duration. Send a string, such as `"30"`. A JSON number does not match the schema.
</ParamField>

<ParamField body="rescheduleUid" type="string">
  Booking uid being moved. That booking is left out of the conflict check.
</ParamField>

The response is the same one the Lunacal platform returns for this route.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/availability \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "startTime": "2026-11-02T00:00:00+05:30",
  "endTime": "2026-11-08T23:59:59+05:30",
  "timeZone": "Asia/Kolkata",
  "eventTypeId": 42
}'
```

</RequestExample>
