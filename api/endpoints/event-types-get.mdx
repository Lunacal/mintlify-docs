---
title: "Get event type"
description: "Retrieve a single event type."
---

<Note>
  Authenticate with `Authorization: Bearer $LUNACAL_API_KEY` and send JSON using POST. [API key setup](/api/authentication).
</Note>

Returns one event type by numeric id, including its locations and `bookingFields`. Required booking questions must be answered in [Create booking](/api/endpoints/bookings-create) under `responses`, keyed by field name.

## Body

<ParamField body="id" type="integer" required>
  ID of the event type.
</ParamField>

The response is the same one the LunaCal platform returns for this route.

<RequestExample>

```bash cURL
curl -X POST https://app.lunacal.ai/api/event-types/get \
  -H "Authorization: Bearer $LUNACAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "id": 42
}'
```

</RequestExample>
