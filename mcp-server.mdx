The Lunacal MCP server lets Claude work in your Lunacal account from a chat. You sign in once in the browser and choose **Allow**. After that, Claude can look up your calendar and, when you approve it, book or change meetings.

You do not paste an API key into Claude. API keys are for your own server. This connection is a separate sign-in.

<Info>
  You need Tier 4 or higher, or MCP access turned on for your account. If you do not have it, the sign-in page sends you back to Settings instead of connecting.
</Info>

## What Claude can do

Claude chooses the action. You describe the task in plain language. Actions that only read your account are safe to run. Actions that book, move, cancel, or edit an event type change real data and can email the other person. Approve those only after the name, time, and event type look right.

### Look something up

| Ask Claude | What it uses |
| --- | --- |
| "Which Lunacal account is connected?" | Your name, email, username, and timezone |
| "What event types do I have?" | Every event type on the account, including team event types |
| "Show me the settings for my intro call." | One event type, including its questions and location |
| "When am I free on Friday for a 30-minute intro call?" | Open times for that event type |
| "What's on my calendar this week?" | Bookings in one of these states: upcoming, recurring, past, cancelled, or unconfirmed |

### Change something

| Ask Claude | What happens |
| --- | --- |
| "Book a meeting with jane@example.com tomorrow at 2pm." | Claude checks open times first, then books one of them. Booking does not search for a free slot on its own. |
| "Move my 3pm meeting to next Monday." | Claude finds the booking, checks the new time, then moves it. |
| "Cancel my meeting with Alex on Thursday." | Cancels that booking. This cannot be undone. Say so in the chat before you approve it. If Lunacal asks for a reason, Claude needs one from you. |
| "Create a 45-minute consultation." | Adds an event type with a title, a link slug, and a length in minutes. |
| "Change my intro call to 45 minutes." | Updates that event type. Questions, locations, and extra settings are replaced as a whole, so Claude should read them before editing part of them. |
| "Hide Office Hours from my booking page." | Publishes or unpublishes that event type. |

Claude cannot edit your weekly working hours. It can see which availability schedule an event type uses, and that is all.

<Warning>
  Booking, rescheduling, cancelling, and editing an event type can notify attendees. Read the details Claude shows you before you approve the action.
</Warning>

## Install it in Claude

<Tabs>
  <Tab title="Claude.ai and Claude Desktop">
    <Steps>
      <Step title="Open the plugin directory">
        In Claude.ai, Claude Desktop, or Cowork, open the plugin directory.
      </Step>
      <Step title="Install Lunacal">
        Find **Lunacal** and install it. On a Claude Team or Enterprise organization, an owner may need to approve the plugin before you can install it.
      </Step>
      <Step title="Sign in">
        The first time you ask Claude to use Lunacal, your browser opens a Lunacal page. Sign in if you are asked to, read the permissions, and click **Allow**.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Claude Code">
    In Claude Code, install the plugin from the Lunacal marketplace:

    ```bash
    /plugin install lunacal --marketplace Lunacal/lunacal-claude-plugin
    ```

    You can also run:

    ```bash
    claude plugin install lunacal
    ```

    Restart the session, then ask Claude something that needs your calendar. The browser opens so you can sign in and click **Allow**.
  </Tab>
</Tabs>

The plugin connects to this address. You only need it if you are adding Lunacal to a client yourself:

```
https://mcp.lunacal.ai/mcp
```

## Try a few prompts

- "Which Lunacal account is connected?"
- "What times are open for my 30-minute intro call on Friday?"
- "Show my upcoming bookings."
- "Book a meeting with jane@example.com tomorrow at 2pm."
- "Move my 3pm meeting to next Monday."
- "Cancel my meeting with Alex on Thursday."
- "Create a 45-minute consultation event type."
- "Unpublish Office Hours."

If a time looks wrong, name the timezone in the prompt, or ask Claude which timezone the account uses. Lunacal stores the moment in UTC and displays it in that timezone.

## If something goes wrong

| What you see | What to do |
| --- | --- |
| Claude asks you to sign in again, or the call is unauthorized | In the client, disconnect Lunacal and connect it again. The sign-in lasts until you remove it. A short-lived access token is refreshed for you. If the refresh is rejected, sign in once more. |
| Lunacal does not appear in the chat | The plugin is installed but not turned on for that conversation. In Claude Code, restart after installing. |
| The sign-in window never opens | Allow pop-ups for the client. If you added the server yourself, the address must be exactly `https://mcp.lunacal.ai/mcp`. |
| "That time is no longer free" | Ask Claude to look up open times again and pick another one. Do not retry the same time. |
| Claude cannot find the booking or event type | Ask it to list your bookings or event types and use a result from that list. |
| You land on Settings during sign-in | This account does not have MCP access. You need Tier 4, or the feature turned on for you. |

## ChatGPT and other clients

Lunacal publishes the connection as a Claude plugin. To add the same server in another client that supports a remote MCP connection with sign-in:

- Server URL: `https://mcp.lunacal.ai/mcp`
- Authentication: OAuth. Do not paste an API key.

ChatGPT's menus change often, so follow the labels in your ChatGPT settings and use the URL above. Clients that can only run a local program are not covered by the Lunacal plugin. Use the hosted address.

For what the sign-in grants, how long access lasts, and how to disconnect, see [MCP access and security](/mcp-security-and-permissions). The field-by-field HTTP reference is the [API introduction](/api/introduction). Claude's argument names differ slightly from those routes. You do not need the HTTP names to use the plugin.
