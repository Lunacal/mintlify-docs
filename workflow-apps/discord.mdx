A Discord step posts the booking into one channel. Allowing Lunacal into the server only adds the bot. You still paste the channel ID, because a server has more than one channel.

<Steps>
  <Step title="Turn on Developer Mode">
    In Discord, open **User Settings**, then **Advanced**, and turn on **Developer Mode**.
  </Step>
  <Step title="Copy the channel ID">
    Right-click the text channel, such as `#general`, and choose **Copy Channel ID**. The value is a number.
  </Step>
  <Step title="Paste it into the workflow">
    In Lunacal, choose Discord and paste that number into **Channel ID**. Do not paste the server name or the server ID.
  </Step>
</Steps>

The message includes the event name, the attendee, the attendee email, the meeting time, and the meeting link when the booking has one.
